# Europe Data Analyst Job Search Checklist

## Roles to search

- Junior Data Analyst / Graduate Data Analyst
- BI Analyst / Junior BI Analyst
- Reporting Analyst
- Power BI Analyst
- Data & Reporting Assistant

Use local-language equivalents where useful, especially for Germany and Switzerland.

## Application preparation

1. Complete the resume with accurate contact details, education dates, exact credential names, issuers, and public links.
2. Publish the portfolio and confirm its GitHub Pages URL works on desktop and mobile.
3. Link directly to the dashboard PDF and any published credentials.
4. Tailor the resume to each vacancy's required tools and responsibilities; only include skills you can discuss or demonstrate.
5. For every role, check work authorization, location, language expectations, relocation assistance, and sponsorship explicitly.

## Search phrases

- `Junior Data Analyst Power BI Germany visa sponsorship`
- `Graduate BI Analyst Switzerland relocation`
- `Junior Reporting Analyst SQL Excel Europe`
- `English speaking junior data analyst Germany`

These are search starting points, not a guarantee that a position sponsors visas. Confirm each listing with the employer.

## Application tracker fields

Company · Job title · Country/city · Link · Date applied · Required skills · Language · Work authorization/sponsorship details · Contact · Follow-up date · Status
