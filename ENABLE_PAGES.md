# Enable this site in 30 seconds

## Option A — Project site (`/portfolio/`)

1. https://github.com/nikhilamaragani-jpg/portfolio/settings/pages
2. Source: **Deploy from a branch** → `main` → `/ (root)` → Save
3. Open: https://nikhilamaragani-jpg.github.io/portfolio/

## Option B — User site (recommended URL)

Repo already created: `nikhilamaragani-jpg.github.io`

1. https://github.com/nikhilamaragani-jpg/nikhilamaragani-jpg.github.io/settings/pages
2. Source: **Deploy from a branch** → `main` → `/ (root)` → Save
3. Open: https://nikhilamaragani-jpg.github.io/

Then set GitHub profile **Website** to that URL.
